Getting started on Paul-Ville

Download the official 2009scape launcher, point it at the Paul-Ville server, and log in.

Official launcher downloads

  • Windows: 2009scape-launcher-sc.exe
  • Linux: TBD — if you play on Linux, tell us how in the Discord server.
  • macOS: Saradomin Launcher macOS artifact
  • Android: Not supported for Paul-Ville.

Server configuration

After the first launcher run creates the config file, edit config.json to point at Paul-Ville and lock it so the launcher does not overwrite it. The ip_management value is shared privately in the Paul-Ville Discord; ask there before completing the edit.

{
  "ip_management": "<ask in Discord>",
  "ip_address": "test.2009scape.org",
  "world": 1,
  "server_port": 43594,
  "wl_port": 43595,
  "js5_port": 43595,
  "ui_scale": 2,
  "fps": 0
}

Windows setup

  1. Download 2009scape-launcher-sc.exe and run it.
  2. Click Play at the bottom. Once the next screen opens, close the launcher.
  3. Open the config folder: press Win+R, type %USERPROFILE%\2009scape, and press Enter.
  4. Right-click config.json, choose Open with → Notepad, and paste the Paul-Ville configuration above.
  5. Save and close Notepad.
  6. Right-click config.json, choose Properties, check Read-only on the General tab, then click Apply and OK.
  7. Relaunch the 2009scape client and click Play.

macOS setup

If you want to use HD on macOS, follow the macOS native HD instructions.

  1. Download the macOS client from the official 2009scape play page.
  2. Try opening the 2009Scape client once. If macOS blocks it, close the warning.
  3. Open System Settings → Privacy & Security, scroll to Security, find the message that 2009Scape was blocked, and click Open Anyway. Authenticate with your password or Touch ID if prompted.
  4. Open the client, click Play, then close it so the config files are created.
  5. Open your home directory and navigate to ~/2009scape/.
  6. Open config.json in a text editor and paste the Paul-Ville configuration above. Save and close.
  7. In Finder, right-click config.json, choose Get Info, and enable Locked under General.
  8. Relaunch the 2009Scape client and click Play.
